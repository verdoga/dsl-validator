# Формат отчёта

`schema/report-v1.schema.json` описывает JSON с `schema_version: 1`. Отчёт содержит идентичность исходного файла, состояние версии, режим и время анализа, полные счётчики и записи источников `parser`, `diagnostic`, `validator`. Диапазоны полуоткрытые. Статусы: `completed`, `completed_with_errors`, `incomplete`; стадии сбоя: `opening`, `parsing`, `reporting` или `null`.

Перед заменой модель полностью проверяется и сериализуется в памяти. Временный файл создаётся рядом, синхронизируется и затем заменяет только отсутствующий либо валидный отчёт того же сценария.
