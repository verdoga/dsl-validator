# Архитектура

`cmd/validator` связывает `webapp`, `workspace`, `pipeline`, `report`, пустой реестр `Diagnostics` и `parseradapter`. Только `internal/parseradapter` импортирует внешний parser; `validatorapi` является read-only границей.

Сканирование последовательно находит файлы и отдельно вызывает parser для версии. Анализ повторно открывает актуальный файл, один раз разбирает его, собирает parser issues, последовательно вызывает совместимые проверки, строит отчёт в памяти и атомарно заменяет JSON.
